# Python-Millionaire-game
It is a basic millionaire game
## How to Run
- Clone this repository
- Run the command: python main.py
## Requirements
-Python 3 and no external libraries used.
## How to Play
- Answer each question by entering 1,2,3 or 4.
- Correct answer- move to next question with higher prize
- Wrong answer -> Game ends.

## Technical Skills Used
- Python Programming Language
- Data Structures: Nested Lists for storing questions,options and answer.
- Control Flow: for loops,if else conditions,break statement.
- String fromet: f string for dynamic output.
- User input handling with type casting(int).
